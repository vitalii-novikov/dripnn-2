# Продукт

## Задача

Владелец не знает, сколько у него вещей и куда перекошен гардероб. Перед
переездом решение «беру / не беру» принимается вслепую. Цена нерешения —
перевезти 100% вещей, включая не надёванные годами.

## Решение

Фото пола с разложенными кучками одежды как главный экран. Кучки — кликабельные
зоны, тап открывает вертикальную галерею вещей. Каждой вещи ставится tier
**S / A / B / C / D** — личное отношение, а не объективная характеристика.

Почему не сетка карточек, как у всех: фото пола эксплуатирует пространственную
память и сразу даёт ощущение объёма.

## Гипотеза

Карта пола + шкала S–D дадут решимость отсеять вещи, которой не даёт таблица.

Контр-гипотеза: возможно, эффект на 90% даёт сам физический акт — разложить всё
на полу и сфотографировать. Тогда приложение после переезда бесполезно. Метрика
живучести существует ровно для этой проверки.

## Пользователи

- **Основной** — владелец, единственный пишущий. Онбординг не нужен.
- **Вторичный** — друзья по публичной ссылке, read-only.
- **Не пользователи** — кому нужен планировщик образов или авто-каталогизация.

## Метрики

| Метрика | Цель |
|---|---|
| Доля отсеянных вещей (primary) | ≥40% |
| Полнота каталога | фото + зона + хотя бы один tier |
| Скорость ввода | ≤10 сек активного времени на вещь |
| Живучесть | ≥1 tier-событие через 3 месяца после переезда |

Метрика «куда перекос» переопределена — см. D1 в [decisions.md](decisions.md).

## Чего не делаем

Обувь и аксессуары, планировщик образов, учёт носки, авто-категоризацию фото,
авто-сегментацию кучек, социальные функции, нативное приложение.
