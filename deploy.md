# Деплой

Всё приложение — три файла в `CODE_Apps_Script/`: `Code.gs` (сервер), `Index.html`
(страница), `appsscript.json` (манифест). Сборки нет: эти файлы и есть
проект Apps Script.

## 1. Форма и таблица

Вопросы формы (названия — буква в букву, можно по-английски):

| Вопрос | Тип | Обязательный |
|---|---|---|
| `Блок` / `Block` | Раскрывающийся список: 9 названий в порядке сетки (слева направо, сверху вниз) | да |
| `Фото` / `Photo` | Загрузка файлов: 1 файл, только изображения | да |
| `Size` / `Размер` | любой | по желанию |
| `Name` / `Название` | Текст (строка) | нет |
| `Tier` / `Тир` | S A B C D E — начальный тир; в приложении его можно поменять | нет |

1. Форма → «Ответы» → «Связать с Таблицами» → **Создать новую таблицу**.
2. Отправить одну тестовую вещь — в таблице появится лист ответов с заголовками.

## 2. Скрипт

В новой таблице: **Расширения → Apps Script**. Дальше один из двух способов.

**Вручную (без терминала).** В редакторе: заменить содержимое `Код.gs` на
`CODE_Apps_Script/Code.gs`; «+» → HTML → имя `Index` → вставить `CODE_Apps_Script/Index.html`;
⚙ «Настройки проекта» → включить «Показывать файл манифеста appsscript.json» →
заменить его содержимое на `CODE_Apps_Script/appsscript.json`. Сохранить.

**Через clasp.** ⚙ «Настройки проекта» → скопировать «Идентификатор скрипта», затем:

```bash
echo '{"scriptId":"<ИДЕНТИФИКАТОР>","rootDir":"."}' > CODE_Apps_Script/.clasp.json
clasp -P CODE_Apps_Script push --force
```

(`clasp login` и включённый Apps Script API — <https://script.google.com/home/usersettings> —
нужны один раз на аккаунт.)

## 3. Настройка

В редакторе выбрать функцию **`setup`** → «Выполнить» → разрешить доступ
(Таблицы, Диск, Формы). В журнале — строка `Готово: форма подключена, блоков в
списке: 9; открыт доступ к фото: N, ошибок: 0`.

`setup` создаёт листы `Blocks` (названия блоков берёт из списка «Блок») и
`State` (тиры и удаления), запоминает ссылку на форму и открывает фото «всем по
ссылке». Запускать повторно можно: если фото не расшарились или форма поменялась.

## 4. Веб-приложение

«Начать развёртывание → Новое развёртывание → Веб-приложение»:
*Выполнять как: я*, *Доступ: только я* (уже в манифесте). Ссылка `/exec` — это
приложение; её удобно добавить на экран «Домой» iPhone.

Через clasp: `clasp -P CODE_Apps_Script create-deployment -d v1`.

## Обновление кода

`clasp -P CODE_Apps_Script push --force` (или вставить файлы вручную), затем
«Управление развёртываниями → изменить → Версия: новая» — ссылка не меняется.
Через clasp: `clasp -P CODE_Apps_Script update-deployment <deploymentId> -d vN`.

## Если висит «Загрузка» или «Сервер не ответил за 15 секунд»

Браузер вошёл в несколько Google-аккаунтов: страница открылась, а вызовы к
скрипту ушли от другого аккаунта. Откройте `/exec` в профиле браузера (или в
приватном окне), где вход выполнен только в аккаунт владельца.
